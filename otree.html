oTree code repository

In this page you can find some oTree* code for Experimental Economics games.

* Chen, D. L., Schonger, M., & Wickens, C. (2016). oTree — An open-source platform for laboratory, online, and field experiments. Journal of Behavioral and Experimental Finance, 9, 88–97.
Norm Following Task
"Norm Following Task" for oTree Lite based on Kimbrough, E. O., & Vostroknutov, A. (2018), implemented for oTree v>5.
